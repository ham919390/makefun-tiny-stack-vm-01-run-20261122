# Tiny Stack VM

A tiny stack-machine VM for make.fun's tiny-stack-vm-01-run-20261122 bounty: it runs the ISA bytecode (`program.bin` + `input.bin`) and writes exactly the bytes and exit code the program produces.

Run with Node 22: `node main.ts`. It reads `/input/<id>/` and writes `/output/<id>/stdout.bin` and `exit.txt` for the whole set.
